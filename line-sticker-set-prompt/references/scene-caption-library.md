# Scene Caption Library

Eight verified sets, transcribed from the published reference set
(小红书 `6a0ef0f90000000008032573`, 8 sticker sheets x 16 captions = 128 cells).
Captions are listed in reading order: left to right, top to bottom.

**Use these verbatim when the scene matches.** They are already tuned for chat usability:
2-6 characters, current slang, no duplicates, and each one reads as something a person would
actually send. Only write new lists when the scene is not covered below.

Notes: covers the full daily loop — morning, night, apology, pout, date. Good template for
any "intimate pair" set. Includes two 5-character and one 6-character caption, so do not
enforce a hard 4-character limit.

Keep that contrast. Two 6-character captions here, the longest in the library.

## 9. Writing a new scene

When the scene is not above, write 16 captions that satisfy all of:

1. **2-6 Chinese characters** each; 4 is the sweet spot, 6 is the ceiling.
2. **Everyday-chat usable** — must make sense as a reply in a real conversation, not a slogan.
3. **No duplicates and no near-duplicates** — swapping one word is not a new sticker.
4. **Cover the arc of the scene**, not 16 synonyms for one feeling. A good set has an
   opening, a middle, a complaint, and a closing (the verified sets all end on a soft beat:
   `明天见`, `下次还来`, `明天再学`, `再来一张`, `明天再做人`).
5. **Slang over formal** — `绷不住`, `破防`, `摸鱼`, `摆烂`, `栓Q` beat textbook wording.
6. **Pair each caption with a distinct prop or body language**, so the model has something
   to vary. If two captions would produce the same picture, replace one.

Scene ideas that map cleanly onto this format: 健身、减肥、养猫、养狗、宝妈、考研、追星、
游戏开黑、饭搭子、早八人、加班狗、面试、看病、省钱、催更、社恐。

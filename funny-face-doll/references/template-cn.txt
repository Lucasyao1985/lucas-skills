# 鬼脸娃娃 I2VA 中文提示词模板

## 模板结构

```
● 视频起始帧：在目标视频的 0.00 秒处，完整参考图片 1（来自镜头 1）。

integrated_multimodal_description: 【镜头 1】实拍电影级竖屏画面，[光线描述]，固定中景镜头拍摄[人物性别]坐在/站在[场景]，完全复刻图片 1 中的造型——[发型]、[眼镜/配饰]、[上装]、[下装]。[手部姿势描述]。身后[背景细节]。[起始动作]。

【镜头 2】在 00:01.000 处，画面跳切，[卡通表情 1 描述]——真实的[头发/配饰保留]仍然[保留姿势]，[轻微动态]。

【镜头 3】在 00:01.500 处，画面跳切回真实面部，[恢复动作 1]。

【镜头 4】在 00:02.000 处，画面跳切为[卡通表情 2 描述]——真实的[保留元素]依然保留，[叠加动作]。

【镜头 5】在 00:02.500 处，画面跳切为[卡通表情 3 描述]——模糊的双手快速拂过脸颊两侧。

【镜头 6】在 00:03.000 处，画面跳切回[卡通表情 1 变体]，眼睛向画面左侧瞟。

【镜头 7】在 00:03.500 处，画面跳切为[卡通表情 4 描述]，双臂高高举起。

【镜头 8】在 00:04.000 处，画面跳切为[卡通表情 5 描述]，[手部动作]。

【镜头 9】在 00:04.500 处，画面跳切回真实面部，[恢复姿势 2]，带着调皮的坏笑向画面左侧瞥一眼。

【镜头 10】在 00:05.000 处，画面跳切为她/他双臂大张，闭眼仰头一脸陶醉；手臂缓缓放下，[恢复到初始姿势]，对镜头露出温和的闭唇微笑。

【镜头 11】在 00:06.500 处，画面跳切为[巨型道具描述]从左下角升入画面，[人物]转头看向[道具]，露出惊喜的张嘴笑容。

【镜头 12】在 00:07.000 处，画面跳切为[人物]双手举到头部两侧做爪状，嘴巴大张夸张大笑，[道具]暂时出画。

【镜头 13】在 00:07.500 处，画面跳切为[人物][与道具的互动姿势]；[最终表情]；她/他保持此姿势直到视频结束。

overall_soundscape: [场景环境音]，每次突然的姿势变换伴随着[衣物材质摩擦声]，结尾处爆发出一声爽朗的开怀大笑。

non_diegetic_music: 一首快节奏电子流行乐，强劲的四四拍底鼓节拍，明亮的合成器钩子旋律，每个跳切点精准卡上重音，全程高能持续至视频结束。

要点说明：
- 首帧锚定：Shot 1 完整复刻图片 1 的[场景/服装/配饰/姿势]，再向后发展动作。
- 跳切结构：13 个镜头对应原片的卡点跳切，切点严格递增且都在 8 秒内；固定机位全程不变。
- 无对白：原片无说话内容，故无 speaker ID；笑声归入 overall_soundscape，BGM 属于角色听不到的后期音乐，归入 non_diegetic_music。
- [道具比例说明]（如有道具）。
- [卡通风格说明]（如使用小丸子等特定风格）。
```

## 变量说明

| 变量 | 说明 | 示例 |
|------|------|------|
| `[光线描述]` | 场景光线 | 温暖自然光从右侧木格窗棂透入 / 明亮自然光 |
| `[人物性别]` | 一位东亚年轻女性 / 一位东亚肌肉型男 |
| `[坐在/站在]` | 根据图片姿势 | 坐在传统日式房间的榻榻米上 / 站在演讲台后方 |
| `[场景]` | 图片中的环境 | 传统日式房间 / 咖啡馆桌前 / 演讲台后方 |
| `[发型]` | 精确描述发型 | 齐耳黑色波波头配齐刘海 / 短黑发 |
| `[眼镜/配饰]` | 图片中的配饰 | 红紫色半框矩形眼镜 / 无框眼镜 / 无 |
| `[上装]` | 上身服装 | 蓝色圆领短袖T恤 / 宝蓝色西装外套搭配浅蓝色衬衫 |
| `[下装]` | 下身服装 | 黑色长裤 / 卡其色高腰短裤 |
| `[手部姿势描述]` | Shot 1 的手部位置 | 左手持白色触控笔抵在嘴唇旁，右手搭在膝盖上 |
| `[背景细节]` | 身后的环境元素 | 深色木质隔断门、红棕色木柜、榻榻米草席地面 |
| `[起始动作]` | 从初始姿势过渡到第一个跳切 | 她放下触控笔，双手同时抬起至头顶比出一个尖顶形状 |
| `[卡通表情 1-6]` | 从表情库中选择的6种卡通表情 |
| `[保留元素]` | 真实保留的特征 | 真实的波波头短发和红紫色眼镜框架 |
| `[巨型道具描述]` | 道具的外观和尺寸 | 一根巨大的卡通香烟道具（白色烟身、橙色滤嘴、顶端冒袅袅白烟） |
| `[场景环境音]` | 与场景匹配的环境音 | 日式房间内轻微的木质地板吱嘎声夹杂窗外远处的蝉鸣 |
| `[衣物材质摩擦声]` | 衣物类型对应的摩擦声 | T恤棉布的轻微摩擦声 / 西装布料摩擦声 |

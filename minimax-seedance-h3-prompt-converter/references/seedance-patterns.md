# Seedance Prompt Patterns (Input Parsing Guide)

Seedance 2.0 / 2.5 提示词没有单一固定格式。转换前先识别输入属于哪种模式，再按九要素清单抽取内容。

## 1. Common Input Styles

### 1.1 字段式（Field-label style）

中文标签 + 冒号，一行一个维度：

```text
主体：一位穿风衣的年轻女性
场景：城市天台，黄昏
动作：她转身面向镜头微笑
镜头：中景缓慢推进
光线：逆光暖色调
氛围：电影感
音效：高空风声
BGM：轻柔钢琴曲
台词：“风好大啊！”
时长：10s
```

解析要点：
- 中文冒号 `：` 与英文 `:` 等价
- 字段可能缺省（无 BGM 行 ≠ 无音乐要求；缺省项按"未指定"处理而不是"无"）
- `时长：10s` 决定总时长基准

### 1.2 时间轴分镜式（Multi-shot timeline style）

以时间段划分镜头块：

```text
0-3s: 固定中景，她背对镜头俯瞰城市
3-6s: 缓慢推镜至近景，她转过身
6-10s: 镜头环绕半圈，灯光渐次亮起
```

时间写法变体（全部要能解析）：
- `0-3s`、`3s-6s`、`0 - 3 s`
- `(0:00–0:01.8)`、`00:01.800-00:02.800`（en dash / em dash / ~）
- `Shot 1 (0:00–0:01.8)` 带编号变体
- 中文：`第0到3秒`、`0秒至3秒`、`0~3秒`
- 单点标记：`at 5s`、`5s处`

批量换算：`python scripts/convert_time.py "0-3s, 3-6s, 6-10s" --style h3`

### 1.3 自然语言叙事式

整段英文或中文散文，时间信息隐含在叙述顺序里。此时按句切分推断镜头边界；无显式时长时默认 10s 并向用户确认。

### 1.4 关键词堆叠式（Keyword style）

逗号分隔的短语，常见于 Seedance 社区工作流：

```text
cinematic shot, a lighthouse in a storm, dramatic lighting, slow dolly in, 35mm, waves crashing, orchestral score
```

解析要点：每个关键词都要归类到九要素之一；`cinematic shot` 类模糊风格词记录待展开。

### 1.5 图片参考式

图片引用标记的常见写法：

| 写法 | 含义 |
|------|------|
| `@图1` / `<图片1>` | 中文圈最常见 |
| `<Picture 1>` / `[Picture 1]` | 已是 H3 风格 |
| `@Image 1` / `Image 1:` | 英文社区 |
| `参考图中的女生` | 无编号自然引用 |

出现任何一种 → 触发身份委托规则（Step 3）。多个不同图引用（角色一张 + 场景一张）→ 倾向 Ref2VA。

### 1.6 分镜网格式（Storyboard grid）

"13-panel storyboard grid"、"四宫格"、"Row 1: 4 panels" 等描述 → Ref2VA 强信号。注意 H3 输出必须声明不复现网格版式：输出为连续单画面视频，不出现分屏、拼贴缝、面板边框。

## 2. Nine-Element Extraction Checklist

逐项打勾后再进入模式判定：

- [ ] 主体设定（人物/动物/物体；有无图片委托）
- [ ] 场景设计（地点、空间关系）
- [ ] 镜头语言（每个时间段/每句的动作机位）
- [ ] 动作逻辑（因果顺序、触发条件）
- [ ] 时间轴（显式时间段 or 隐含顺序）
- [ ] 摄影参数（焦段、画幅、景深、机位高度、颗粒感）
- [ ] 光线设计（方向、色温、时段）
- [ ] 氛围（风格标签）
- [ ] 声音设计（台词 / 音效 / BGM 三类分开记录）

## 3. Residue Markers（转换后必须消失的痕迹）

以下 Seedance 特征出现在最终 H3 输出中即为残留，validate_h3.py 会报错：

- 时间段写法：`0-3s`、`(0:00–0:01.8)`、`第0到3秒`
- 中文字段标签：`主体：`、`场景：`、`动作：`、`镜头：`、`运镜：`、`光线：`、`氛围：`、`音效：`、`BGM：`、`台词：`、`时长：`
- 图片引用原样残留：`@图1`、`<图片1>`、`@Image 1`（应已转为 `<Picture N>` 或并入 subject_definitions）
- 分镜网格指令残留："storyboard grid"、"panels"、"宫格"

## 4. Ambiguity Protocol

| 歧义 | 处理 |
|------|------|
| 无总时长 | 默认 10s 并在交付时注明假设 |
| 图片用途不明（首帧？角色设定？） | 问用户；不能问时按对生成结果影响最小的方式判定并说明理由 |
| 台词语言与正文语言不一致 | 正常现象——台词保留原文，语言标签如实标注 |
| BGM 未说明是否角色可闻 | 默认 non-diegetic 写入 non_diegetic_music |

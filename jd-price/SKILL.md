# /jd-price - 京东价格智能分析

✅ **核心功能：**
- 🔍 商品搜索 — 输入链接/SKU/名称即可查询
- 📊 价格分析 — 判断当前价格是否值得买
- ⚖️ 多商品对比 — 生成对比表和购买建议
- 📈 价格监控 — 记录价格变化
- 📄 HTML报告 — 商务风格可视化报告


## 📌 调用方法

```
/jd-price <商品链接 | SKU | 商品名称>
```

### 示例:
```
/jd-price https://item.jd.com/100012345.html
/jd-price 100012345
/jd-price 小米15 Ultra
/jd-price 小米15 Ultra vs vivo X300 Pro
/jd-price 对比: 小米15 Ultra, vivo X300 Pro, OPPO Find X9
```


## 🔧 工作流程

### Step 1: 识别输入类型

| 输入类型 | 识别方式 | 处理方法 |
|---------|---------|---------|
| 京东链接 | 包含 `item.jd.com` 或 `jd.com` | 直接提取SKU |
| SKU编号 | 纯数字或数字字符串 | 构建链接 |
| 商品名称 | 文本 | 搜索京东 |
| 多商品 | 包含"对比"/"vs"/逗号分隔 | 批量查询 |

### Step 2: 获取商品信息

使用 WebFetch 访问京东商品页面：
```
https://item.jd.com/{SKU}.html
```

**提取信息：**
- 商品名称
- 品牌
- 型号
- 当前售价（J_CURRENT）
- 券后价（如有优惠券）
- 满减活动
- Plus会员价
- 店铺名称
- 商品主图
- 评分
- 评论数
- 库存状态

**数据源优先级：**
1. 京东商品页面直接提取
2. 京东搜索结果页
3. 搜索引擎缓存

**重要：禁止凭空猜测价格。如无法获取，明确说明。**

### Step 3: 价格分析

**评级标准：**

| 评级 | 标识 | 条件 |
|-----|------|------|
| 🟢 值得买 | GOOD | 价格处于历史低位 / 大幅优惠 / 性价比高 |
| 🟡 可观望 | WATCH | 价格适中 / 无明显优惠 / 可等促销 |
| 🔴 不推荐 | BAD | 价格偏高 / 有更好替代品 / 建议等待 |

**分析维度：**
- 当前价格水平
- 是否有优惠券/满减
- Plus会员价优势
- 库存充足度
- 同类竞品价格

### Step 4: 多商品对比（如有）

生成对比表：

```markdown
| 项目 | 商品A | 商品B | 商品C |
|------|-------|-------|-------|
| 当前价格 | ¥xxxx | ¥xxxx | ¥xxxx |
| 优惠后价格 | ¥xxxx | ¥xxxx | ¥xxxx |
| 店铺 | xxx | xxx | xxx |
| 评分 | x.x | x.x | x.x |
| 评论数 | xxx | xxx | xxx |
```

**推荐维度：**
- 💰 性价比推荐
- ⚡ 配置推荐
- 🎯 购买建议

### Step 5: 价格监控（如有请求）

记录监控数据：
```json
{
  "sku": "100012345",
  "name": "商品名称",
  "url": "https://item.jd.com/100012345.html",
  "price": 2999,
  "timestamp": "2026-06-04T10:00:00"
}
```

后续查询时自动比较：
- 📈 涨价：+¥xxx (+x.x%)
- 📉 降价：-¥xxx (-x.x%)

监控数据保存路径：`C:\Users\Lucas\.claude\skills\jd-price\monitors\`

### Step 6: 生成HTML报告

自动生成商务风格HTML报告。

**报告特性：**
- Apple风格卡片布局
- 深浅色自适应（跟随系统）
- 响应式设计
- 商品图片展示
- 价格趋势模块
- 对比表模块
- 推荐结论模块

**保存路径：**
```
C:\Users\Lucas\.claude\skills\jd-price\reports\yyyy-mm-dd\jd_price_report.html
```

## ⚠️ 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 无法获取价格 | 明确说明"当前无法获取实时价格数据" |
| 商品下架 | 提示商品已下架，建议搜索替代品 |
| 网络超时 | 重试一次，仍失败则报告错误 |
| SKU无效 | 提示SKU不存在，建议检查 |
| 页面结构变化 | 尝试备用解析方法 |

## 🔗 数据来源

## ⚠️ 已知限制（测试于 2026-06-04）

| 限制 | 说明 | 解决方案 |
|-----|------|---------|
| **字体加密** | 价格使用字体加密显示 | 需要解密字体或使用浏览器渲染 |
| **频控检测** | 自动化访问会被检测并阻止 | 使用真实浏览器或降低频率 |
| **价格隐藏** | 未登录用户无法查看价格 | 需要登录账号 |
| **搜索反爬** | 搜索页面有验证码保护 | 直接使用商品链接/SKU |
| **API变化** | 京东API经常变化 | 需要持续更新 |

### 测试结果

**可获取的信息：**
- ✅ 商品名称（通过curl）
- ✅ 品牌、型号
- ✅ 库存状态（是否下架）
- ✅ 店铺名称（部分）

**无法获取的信息：**
- ❌ 实时价格（字体加密）
- ❌ Plus会员价
- ❌ 优惠券详情
- ❌ 评分/评论数

### 技术分析

1. **字体加密**：京东使用自定义字体加密价格数字，页面显示`1??9`而非真实价格
2. **频控机制**：检测到自动化访问后返回"PC频控页"
3. **Cookie有效性**：Cookie有效但无法绕过字体加密
4. **API不可用**：商品详情API已下线或变更

### 替代方案

1. **手动输入价格**（最可靠）：
   - 用户在京东APP/网页查看价格
   - 手动输入价格后进行分析和对比

2. **使用浏览器插件**：
   - 慢慢买：显示历史价格趋势
   - 什么值得买：显示优惠信息
   - 京价保：自动比价

3. **使用第三方比价网站**：
   - 慢慢买：`https://tool.manmanbuy.com/historyLowest.aspx?url={京东链接}`
   - 什么值得买：`https://www.smzdm.com/`

4. **使用京东APP**：
   - 京东APP显示真实价格
   - 可截图后识别价格

**推荐方式**：用户手动输入价格，技能负责分析、对比和生成报告

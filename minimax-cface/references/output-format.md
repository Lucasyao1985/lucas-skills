## 各栏写作规则

| 栏目 | 规则 |
|---|---|
| 【风格】 | 固定含「抖音爆款搞怪变脸短视频（Viral Funny Elastic Face FX）」；实景类型跟随参考图（真人/毛绒玩偶/手办等）；禁止场景绑定词（夜景、街头、打光方向） |
| 【时长】 | 默认 10 秒 |
| 【场景】 | 默认完全沿用 @图片1，不写死任何环境细节；仅当用户明确要求新场景时才改写 |
| 【角色】 | 按参考图具体描写（材质→五官→标志部位→体型），非通用化；末尾必须附一致性约束整句 |
| 时间轴 | 四镜头默认 2/3/3/2 秒节奏；用户指定时间轴时严格照搬（模式 2） |
| 机位 | 景别 + 视角 + 镜头动态（手持晃动/锁定/推拉/震动），每镜头一条 |
| 动作 | 双手动作必须左右显式拆解；形变必须有因果触发点（拍/拉/吹/喊） |
| 特效 | 中文描述 + 英文特效标签括注；必须含材质保持声明 |
| 音效/声音设定 | 逐动作拟声（啵/啾/咻/唰）+ 结尾台词 + 卡点音效；I2VA 模式声音必须完整描述 |

## 节奏设计（传播优化）

- **前 2 秒**：第一个形变爆点必须在 2 秒内出现（吸引力钩子）。
- **中段（2-8 秒）**：两个递进爆点，强度逐级升高（拉嘴 → 膨胀 → 弹射/旋转）。
- **结尾（8-10 秒）**：Punchline 收尾——贴脸喊台词 / meme 定格 / 表情反差；音效给最大动态（喊声+回声+震动）。
- **反差镜头**：镜头 4 前段安排「无任何形变的正常状态」（如怪兽爪咆哮），与前面形变形成反差萌。

## 模式 2 二创检查清单

- [ ] 原提示词的主题、故事、镜头顺序、时间轴、摄影语言、动作逻辑全部保留
- [ ] 仅替换角色身份/外貌/材质/行为描述
- [ ] 角色行为已适配新角色身体特征（无发→眼珠；有角→避开角）
- [ ] 新增特效不超过原提示词复杂度，且全部来自特效库
- [ ] 结尾 Punchline 与音效完整
- [ ] 一致性约束整句已写入【角色】栏

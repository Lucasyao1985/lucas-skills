# MiniMax-CFace 可爱脸病毒短视频

基于角色参考图的 MiniMax-H3 可爱脸病毒短视频创作 Skill。把任何上传角色转换为 **Cute Character + Funny Face FX + Viral Meme Video** 类型的 H3 Ready 视频提示词。

## Workflow

1. 判断工作模式：用户只上传角色图 → 模式 1（默认创作）；用户给了已有视频提示词 → 模式 2（提示词二创）。
2. 按 `references/output-format.md` 的统一格式输出；特效措辞参考 `references/fx-library.md`；写作前可对照 `references/examples.md` 的实战案例校准夸张度与节奏。
3. 输出前逐条过「角色一致性规则」与「禁止事项」自检。

## 模式 1：默认创作模式

输入：仅角色参考图，无需提示词。自动执行：

1. **角色分析**：脸部结构、五官特点、发型（或角/耳等替代特征）、服装、身材比例、材质特点、角色气质。
2. **自动生成创意**：可爱搞怪剧情、夸张动作、Meme 反转、爆点结尾。
3. **默认加入**：Funny Face Transformation、Elastic Deformation、Cute Reaction、Cartoon Physics、Viral Ending。

## 模式 2：提示词二创模式

三层处理，缺一不可：

- **第一层 保留原内容**：原主题、原故事、原镜头顺序、原时间轴、原摄影语言、原动作逻辑一律不动。
- **第二层 角色融合**：替换主角身份、外貌描述、材质描述、角色行为；角色行为必须适配新角色身体特征（无头发→改用角/耳/眼珠；有角→动作避开角）。
- **第三层 可爱脸增强**：按需加入面部特效（Rubber Mouth Stretch / Elastic Face Deformation / Giant Head Morphing / Funny Eye Transformation）、身体特效（Squishy Physics / Cartoon Bounce / Cute Monster Reaction），并强化节奏——前 2 秒吸引力、中段视觉爆点、结尾 Meme Punchline。

## 默认视频风格：Viral Cute Face FX

4K 超清、角色实景、高质量材质、真实光影。效果标准：**夸张但保持可爱，搞笑但不恐怖，卡通物理但保持真实材质**。

## 角色一致性规则（硬约束）

- 全程同一角色：脸部特征、材质、服装、颜色全部以上传参考图为准，严格保持一致，不做替换或增减。
- 【角色】栏必须写明「以上传参考图为准，全程严格保持一致，不做任何替换或增减；全片仅对该角色施加形变特效，角色始终为参考图本人」。
- 材质跟随参考图（真人→肤质；毛绒→绒毛质感），形变特效描述中必须回扣材质。
- 禁止：换脸、改变角色身份、添加参考图不存在的元素、改变角色核心设计、恐怖化、无意义随机变形、降低角色质量。

## 实战铁律（源自迭代验证）

1. **双手动作必须显式拆解**：写「左手与右手同时…两根手指分别插入左侧嘴角和右侧嘴角，双手同步对称发力」，并加约束「画面中自始至终必须同时可见左右两只手，严格禁止单手或一只手出画」。刻意单手的触发动作除外（需注明「刻意单手」）。
2. **场景默认沿用参考图**：【场景】栏写「以@图片1原有场景为准（环境、背景、光线与氛围完全延续参考图，全程不做场景切换或替换）」；风格栏不得出现与参考图冲突的场景绑定词（如夜景、街头）。
3. **无头发角色不设计头发动作**：改用眼珠（高速旋转/弹射）、角、耳朵等该角色实际特征做变形点。
4. **结尾必须有 Punchline**：贴脸大喊一句台词、meme 文字爆炸后吸回、表情定格等，音效同步（喊声+回声混响+卡点音）。
5. **夸张度校准**：拉伸要写到超出画面预期（如「宽到超出肩膀、横贯画面」）+ 回弹余震（果冻式抖动）；膨胀用递增式（每拍一下大一圈）+ 泄气式复原；结尾爆发配镜头震动与音波冲击纹。
6. **特殊部位避让**：有角/帽饰/长耳的角色，拍头动作注明「避开牛角」等。

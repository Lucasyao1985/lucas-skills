# 生图提示词设定模板（MiniMax Design 提炼版）

## 这个 skill 做什么

不直接写一次性的生图提示词，而是为项目产出**「生图提示词生成器设定」**：一段可复用的 system prompt（角色定调 + 刚性约束 + 变量槽位 + 提示词模板 + 硬性规则 + 示例），交给任意对话模型或写入应用后，每次只需填变量就能得到可直接投喂生图模型（GPT Image 2 / Seedream / 即梦等）的最终提示词。

与 `minimax-video-prompt-template` 配套：本 skill 负责流水线上游——先产出角色设定图、场景图、首帧图、末帧锚定图，供视频 skill 的 I2VA / 多模态参考模式使用。

## 何时使用

- 用户要把某个项目/风格沉淀成生图提示词模板（"帮我把XX做成生图的skill"、"写个生图生成器"）
- 用户需要批量出图并保持一致性（同系列商品图、同角色多张、同风格分镜）
- 图生视频流水线的上游（先定图再动图）
- 用户拿不准生图提示词怎么组织变量和硬规则时

## 工作流

### Step 0：收集项目信息（一次性问清，缺项给默认值）

1. 最终产物是什么图？（单图 / 成套图 / 单张多格拼图 / 编辑已有图）
2. 风格方向？（写实摄影 / 二次元 / 3D / 扁平插画 / 特定艺术风格——风格词必须特征化，见 style-anchor-library.md）
3. 有无参考图？参考图管什么（身份 / 风格 / 构图 / 配色）？
4. 画幅与张数？
5. 有无必须逐字出现的文字？
6. 交付形态：直接出提示词，还是产出可复用的生成器设定？

### Step 1：选场景模板

读 `references/scenario-templates.md`，按下表选定场景后套用该场景的变量槽位与骨架差异：

| 场景 | 变量特征 | 硬规则重点 |
|---|---|---|
| 电商商品图套件 | 品类/SKU属性/平台/图型组合 | 平台规格显式写入、真实数据红线、背景×主体配色移一档 |
| 海报/封面 | 子类/画幅/文案原文/品牌色HEX | 文案逐字且全图只出现一次、构图5模式、画幅禁止默认1:1 |
| 角色设定图/三视图 | 角色卡/风格五件套/版式 | 禁 left/right/mirror 镜像词、表情表4+3网格、风格词典整行抄写 |
| 分镜板/宫格图 | 剧本/格数/画幅 | 每格自包含、参考图只管风格不管叙事、节拍映射 |
| 风格化插画 | 场景\|服装\|动作\|色系 | 抗写实刚性约束、色域锁、五官比例分档 |
| UI/截图样机 | 平台/文案/语言/作者 | 内外画幅分离、字体锁、单张完整画面 |
| 照片编辑/remix | 底图+改动范围 | R1/R2/R3 替换子句、保留清单、字体名转视觉特征 |

### Step 2：组装生成器设定

读 `references/generator-skeleton.md`，按七段范式组装：

```
角色定调 → 抗漂移刚性约束 → 变量解析 → 输出规范 → 提示词模版(带{槽位}) → 硬性规则 → 完整示例
```

### Step 3：填充风格锚 / 构图 / 负向

- 风格词特征化、媒介锁、配色锁 → 读 `references/style-anchor-library.md`
- 画幅、构图模式、光影条款、通用负向词、defaults 默认表 → 读 `references/composition-clauses.md`

### Step 4：有参考图或编辑需求时

读 `references/reference-identity-lock.md`，加参考图协议、身份锁卡、编辑替换子句（R1/R2/R3）。

### Step 5：门禁自检后交付

自检清单（见下）通过后，交付三件套：

1. **生成器设定全文**（可直接粘贴为 system prompt）
2. **变量槽位表**（变量名 | 说明 | 示例 | 是否必填）
3. **一份填好的示例提示词**（验证生成器可用）

## 通用六层骨架（速查）

任何生图提示词都按这六层组装，场景模板只改变各层的具体条款：

```
① 任务锚定层   角色定调（"你是顶级XX提示词工程师，唯一任务是…"）
                或变换声明（"Transform X into Y"）+ 输出纯性声明（"只输出提示词本体"）
② 媒介风格层   Medium Lock 显式声明媒介 + NOT 排除邻近媒介；
                风格 DNA 关键词前缀逐字透传；抽象风格词翻译成可见特征
③ 主体身份层   Identity Lock 卡（脸/发/服/配饰/比例 8-12 项逐字复用）；
                参考图协议 Name+Role+Take+Ignore；视觉类型不互转
④ 场景构图层   画幅显式声明；主体占比区间；构图模式或分块禁令；
                背景×主体配色关系；禁 left/right 镜像词
⑤ 光影细节层   光的方向/色温/物理一致性；材质转译；
                文字渲染策略（≤4字走图内渲染，≥5字走底图+后期）
⑥ 负向层      风格 specific negative + 通用 negative + 反模式 negative
```

## 简单场景快写（不读 references 的最小路径）

用户只要一张图的提示词时，用一段式骨架：

```
[画幅]的[媒介与风格完整特征句]，[主体身份完整描述]，[动作/状态]，
[场景与前中后景]，[光影与色调]，[质感与细节]。
Negative: [风格风险词 + 通用词]
```

硬规则四条：画幅显式写；风格词翻译成可见特征；文字逐字引用且只出现一次；负向只列真实风险 5-10 项。

## 门禁自检清单

1. 画幅是否显式声明（禁默认 1:1）？
2. 风格是否已特征化（没有只写"高级感/国风"这类抽象词）？
3. 主体身份是否锁死（有参考图时零预设、零历史沿用）？
4. 文字是否逐字引用、全图只出现一次、拼写正确？
5. 媒介锁是否有 NOT 排除（防写实/防卡通漂移）？
6. 负向词是否只打真实风险（不超过 10 项）？
7. 输出纯性是否声明（只输出提示词本体、无 Markdown、无解释）？
8. 成套图是否共享同一风格锚 + 同一默认参数表？

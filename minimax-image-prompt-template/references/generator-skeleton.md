# 生成器设定七段范式

「生成器设定」是一段 system prompt：粘贴给任意对话模型后，用户每次发送变量 + 参考图，模型输出可直接投喂生图模型的最终提示词。以下七段是通用范式，缺一不可，顺序固定。

## 七段结构

```
第一段 角色定调        你是一名顶级 XX 提示词工程师。唯一任务是：根据收到的变量和参考图，
                      生成一段可直接交付 [生图模型] 使用的最终生图提示词。
第二段 抗漂移刚性约束  【Iron Laws】最易翻车的 3-6 条写在最前，用"严禁/必须"句式。
                      例：绝对 2D 平面、禁摄影写实、禁立体阴影、禁透视纵深。
第三段 变量解析        输入格式：字段1 | 字段2 | 字段3（分隔符固定、顺序固定）。
                      声明：每次以本次输入为唯一来源，不得沿用示例值或历史值。
第四段 输出规范        ①只输出提示词本体，无前缀/标题/Markdown ②必须以[锚定句]起始
                      ③字数区间 ④纯文本自然分段，不用星号井号
第五段 提示词模版      完整模板正文，{槽位} 用花括号标出，槽位外的骨架句逐字保留
第六段 硬性规则        编号列表：变量替换规则、身份规则、禁改项、缺输入时行为
第七段 完整示例        一份填好所有槽位的成品（让模型对齐输出格式）
```

## 两条已验证的黄金范式

### 范式 A：风格化插画型（变量少、风格刚性极强）

适用：固定艺术风格 + 每次换内容。参考实现：奢华丝网插画生成器。

```text
你是一名顶级 AI 图像提示词工程师。你的唯一任务是：根据收到的四个动态变量，
以及随消息附带的唯一一张人物照片，生成一段可以直接交付 GPT Image 2 使用的
横屏 16:9 奢华丝巾装饰插画纯文本生图提示词。

【抗写实与平面化刚性约束】
1. 绝对 2D 平面：严禁任何三维体积感、胶片质感、摄影写实质感、写实光影、
   次表面散射或景深虚化；全画采用法式清线与纯平色块。
2. 面部反漂移：严格将参考人物的面部重构为"平面工笔白描风格"——细黑闭合
   线条勾勒眼眶与鼻唇，平涂象牙白肤色，严禁立体阴影过渡。
3. 背景去纵深：建筑与景物全部转化为立面展开的装饰花纹与剪影拼贴，
   禁止任何写实透视收缩。
4. 构图规范：中景大半身端坐（占画面高度 65%-75%）；四分之三微侧脸，
   严禁 90° 纯侧脸或纯正面证件照角度。

【变量解析】输入格式：场景空间 | 时代与服装 | 动作与道具 | 宝石色系

【输出规范】
1. 仅输出一段纯文本提示词，无任何前缀、标题或 Markdown。
2. 必须以"横屏 16:9 的奢华丝网装饰插画"起始。

【提示词模版】
（固定风格锚定段，含 {服装}{动作}{场景}{色系} 四个槽位…）
```

要点：风格锚定段整段写死在模板里，槽位只出现在"内容层"；四条 Iron Laws 对应这种风格最会翻车的四个点（3D 漂移、脸写实、背景纵深、构图跑偏）。

### 范式 B：复杂画面型（单图多区域、多文字、多约束）

适用：一张图里有多个区域、多段文字、多个角色副本。参考实现：社交平台截图生成器。

要点差异（相对范式 A）：
- 开头先声明**整体画面结构**："最终目标是生成一张完整的 XX 画面。整个成品只有一张完整画面"——防模型拆出多图。
- 逐区域给规则：顶部区/作者区/正文区/图格区/互动区，每区一段。
- **多副本同一性**："头像、正文配图中的人物、标语牌人物都必须表现为同一人物"，并声明哪些区域不是额外输入图而是"由模型直接生成并嵌入"的内容。
- **视觉类型保持**：输入照片是写实就保持写实，是动漫就保持动漫，禁止互转。
- 硬性规则里写"不得出现参考图/输入图片/变量等制作流程术语，直接描述最终画面内容"。

### 范式 C：条款式协议型（成套图、跨图一致性）

适用：一次产出成套图（多图型、多 SKU）。参考实现：电商图六型套件。要点：
- 用 C1-C11 编号条款代替连续模板（每条一个独立规则，见 composition-clauses.md）。
- 目标提示词 200-400 词，覆盖优先于字数。
- 六维加权评分门禁（构图/光影/主体/文字/平台合规/一致性），P0 项低于 6 分重写。
- 属性卡声明"不得编造"的字段：品牌、规格、成分、认证、功效数字、包装文字；缺数据→砍图不造假。

## 变量槽位设计规则

1. **Step0 一次问清**：画幅/风格/文案原文/张数四项不齐不生成，给默认值表兜底。
2. **枚举优先**：能枚举的变量（子风格/构图模式/光方向）给选项库，不要自由文本。
3. **零预设零历史**：每个变量声明"以本次输入为唯一来源，不得沿用示例值或历史值"。
4. **字符级变量**（文字上屏类）单独声明："逐字使用原文，不改写、不增删、不加装饰、不乱码；非拉丁字符保持原样"。
5. **可选变量**明确标注非必填及缺省行为（"未提供则按角色气质动态设计"）。

## 交付前自检

- [ ] 七段齐全，顺序正确
- [ ] 槽位外的骨架句逐字固定（模型只换槽位不重写骨架）
- [ ] Iron Laws 对准本项目最会翻车的 3-6 个点
- [ ] 输出规范含锚定起始句 + 纯文本要求
- [ ] 示例里所有槽位已填死，无残留花括号
- [ ] 变量表与模版中的槽位一一对应

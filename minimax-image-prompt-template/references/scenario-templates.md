# 七大场景模板速查

每个场景给出：变量槽位表、骨架差异、特有硬规则。通用六层骨架见 SKILL.md，此处只写差异。

## 场景 1：电商商品图套件

变量：`品类+子类 | SKU色/材质(英文) | 平台 | 图型组合 | 模特/场景需求`

图型六型（每型一段独立提示词）：白底图 / hero 场景图 / 细节微距图 / lifestyle 图 / 尺寸参考图 / 多角度图。

特有硬规则：
- 平台规格（画幅/像素/文件约束）显式写入每条提示词，无平台默认值。
- 真实数据红线 8 类：品牌、规格、成分、认证标志、功效数字、包装文字、模特身体数据——缺数据砍图不造假。
- 细节图三规则：无皮肤 + 单焦点 + 统一背景族。
- 同系列跨图一致：共享身份锁卡 + 同一 Aesthetic Baseline（风格方向/色板/光宇宙/调色/节奏轴八维）+ "one shoot one day"（同批图同一拍摄条件语言）。
- Pilot Gate：先出 1 张锚定图，用户确认后再批量。

## 场景 2：海报 / 封面

变量：`子类(小红书封面/公众号头图/电影海报/专辑封面…) | 画幅 | 文案原文 | 品牌色HEX`

特有硬规则：
- 同一文案在图中只出现一次（防幻觉重复排版）。
- 构图必须用五模式之一（见 composition-clauses.md），禁几何分块。
- 加反色块负向词组。
- 高危雷区按子类查（如公众号头图 2.35:1 顶部安全区、小红书 3:4 首图信息密度）。

## 场景 3：角色设定图 / 影视资产

变量：`角色卡 | 风格五件套(STYLE_*) | 版式类型 | 画幅`

版式库：三视图（16:9 深灰底，居中三姿）/ 表情表（≤7 张 4+3 网格）/ 姿势表（按人设推荐姿势风格）/ 道具多视图 / 场景概念图（多角度或同时段光）。

特有硬规则：
- 空间语义规避三规则（禁 left/right/mirror，见 composition-clauses.md §5）。
- STYLE_* 整行抄写，禁止跨风格混用。
- 场景概念图用 LAYOUT LOCK（物件位置冻结只动机位）。
- 大综合设定图（角色三视图+场景+12格分镜单张）：{LAYOUT_INSTRUCTION} 写相对权重不写坐标；分镜格含镜号+景别+内容+情绪+≤15字说明。

## 场景 4：分镜板 / 宫格图

变量：`剧本/故事 | 格数 | 画幅 | 风格`

特有硬规则：
- 每格**自包含**描述（不依赖上一格语境），风格 profile 全格统一。
- 参考图只管视觉风格（最高权威），分镜表只管叙事内容——两者冲突时风格赢。
- 节拍映射：起(state)→动作→高潮→end state；格数不够合并节拍，禁凑事件。
- 12 格节奏参考：01 建立镜头 → 04-05 特写情绪 → 08-09 大特写 → 12 全景收束。
- 输出：分镜表 + 一张 N 宫格整图（2x2 到 5x5），禁多图输出。
- 分镜草稿用火柴人/黑白（只取轮廓与空间，不复制服装材质到正式图）。

## 场景 5：风格化插画 / 艺术风格

变量：`场景空间 | 时代与服装 | 动作与道具 | 色系`（四字段管道分隔）

特有硬规则（按所选风格从下列库取用）：
- 抗写实四条：绝对 2D 平面 / 面部反漂移 / 背景去纵深 / 构图规范（见 generator-skeleton.md 范式 A）。
- 色域锁：只用指定宝石色系，形成套色印染效果。
- 二次元：通用 negative 表 + 五官比例分档 + 主题兼容检查（子风格有禁用主题表）。
- 东方弥散类：去真实感声明 + 轮廓器物化剪影 + 内部分层弥散（亮核→过渡带→外晕）+ 结尾"不是什么"（非照片/非卡通/非水墨）。
- 3D 潮玩卡：两头身比例/软胶材质/配件厚度与接触阴影/背景禁灰白用彩色纯色/边框留呼吸边距。
- 静图提示词**禁止混入运动词汇**（loop/wave/flowing），运动词属于视频阶段。

## 场景 6：UI / 截图样机

变量：`平台 | 作者名 | 事件/文案 | 语言`

特有硬规则：
- 单张完整画面：状态栏+导航+内容区+互动区+输入框必须同一画面，禁生成多张/第二部手机/电脑浏览器窗口。
- 内屏永远真实手机比例，禁拉伸；外画幅与内屏比例分离声明。
- 字体锁：英文 SF Pro 比例、中文 PingFang 比例，禁瘦高字/压 line-height。
- 真实截图质感：系统字体渲染 + 轻微屏幕压缩痕迹；禁 UI 设计稿感、网页模型感。
- 平台 UI 元素按该平台真实移动端视觉语言选配，不机械套其他平台布局；无对应认证样式不强加。
- 图内多区域人物（头像+配图）必须同一人：视觉类型保持规则逐区域声明。

## 场景 7：照片编辑 / 重混

变量：`底图 | 改动类型(重打光/局部改/remix/字效迁移) | 改动参数`

特有硬规则：
- 先判定模式：局部编辑（R2）/系列重生（R1）/材质修复（R3）/全图 remix（三轴）。
- 局部编辑必须 image-edit 底图当画布，**绝不跑 fresh seed 文生图**（头号翻车点）。
- 编辑指令三要素：改动区域显式 + 新内容完整视觉描述 + 必须不变元素清单。
- remix：Form/Aesthetic/Mood 三轴确认保留与替换，只改受影响轴。
- 重打光：物理一致性（高光=投影方向，彩色光影响邻近表面）。

# 风格锚定库：媒介锁、特征化翻译、配色锁

## 1. 媒介锁（Medium Lock）

风格漂移的头号原因是媒介未声明，模型自行混入邻近媒介。规则：

- 显式写正媒介 + 用 NOT 排除邻近媒介，成对出现：

```
Medium: photorealistic still photography. NOT illustration, NOT 3D render, NOT painting.
Medium: flat 2D vector illustration. NOT photorealistic, NOT 3D, NOT watercolor texture.
```

- 成套图全组统一媒介锁，逐张重复写入。
- 负向词里再压一次（见 composition-clauses.md 负向层）。

## 2. 抽象风格词 → 可见特征翻译

模型不认识"高级感/国风/复古/赛博"。写风格时必须翻译成可见可判定的特征，五件套：

```
线条特征：细黑闭合轮廓线 / 粗糙马克笔触 / 无轮廓纯色块
上色特征：高饱和平涂 / 低饱和水彩晕染 / 赛璐璐分层阴影
比例特征：写实人体比例 / 两头身Q版 / 九头身时装画
质感特征：哑光丝印颗粒 / 釉面陶瓷高光 / 做旧纸张纹理
年代媒介：18世纪洛可可宫廷细密画 / 90年代VHS截图 / 2020s 3D潮玩渲染
```

示例（"国风"翻译后）：
> 工笔重彩平涂技法，细密均匀的墨线勾勒，矿物颜料高饱和色块，enveloped 高密度缠枝牡丹与飞檐亭台纹样，宣纸哑光质地

## 3. 风格词典整行抄写机制（STYLE_* 五件套）

多风格项目（用户可选风格）建立风格词典，每个风格一行完整描述，生成时**整行抄写、禁止跨风格混用**：

```
{STYLE_LINE}:    一句话风格定义（含媒介+年代+流派）
{STYLE_LINES}:   线条与上色特征组
{STYLE_COLOR}:   色板（HEX + 名称 + 占比）
{STYLE_TEX}:     材质与纹理组
{STYLE_NEG}:     该风格专属负向词
```

关键约束：选了 S6 二次元风格，就不能在负向词里禁 anime style——负向词与所选风格联动。

## 4. 配色锁

- 品牌色/主色必须**字面写 HEX 值 + 名称 + 占比**三要素：
  `主色 #FF6B35 珊瑚橙（占画面 30%），辅色 #1B2A4A 深藏青（占 20%），底色象牙白（占 50%）`
- 色域锁（编辑/重绘场景）：只允许使用原图已有色相，只允许明暗变体，禁止引入新色相。
- 背景×主体配色关系（电商条款 C1）：背景与产品为同族色时移一档明度/饱和度拉开层次；例外句：`Amazon 主图必须纯白背景 RGB(255,255,255)，产品不受此限`。

## 5. 防写实漂移声明（非写实风格必加）

二次元/扁平/插画/3D 卡通风格，四件套逐条写入：

```
① 媒介锁 + NOT photorealistic
② 面部处理：平涂肤色、单线勾勒五官、禁立体阴影过渡、禁写实皮肤纹理
③ 光影处理：无渐变阴影、无环境光遮蔽、无次表面散射、无景深虚化
④ 负向压制：realistic photo, photorealistic, realistic skin texture, depth of field…
```

## 6. 五官比例分档（二次元族）

| 档位 | 适用 | 特征 |
|---|---|---|
| 萌系 | Q版/儿童向 | 大眼占脸 1/2，鼻嘴极简，圆脸 |
| 少年漫 | 热血/通用 | 眼占脸 1/3，棱角脸，鼻梁有结构 |
| 写实向 | 青年/古风 | 五官接近真人比例，眼型细长 |

## 7. 文字渲染策略

- 图内文字 ≤4 字（标题、logo）：可走图内渲染，逐字引用 + 声明字体气质 + 位置 + 颜色。
- ≥5 字的长文案：走"底图留白区 + 后期排版"，提示词只写留白区域位置与尺寸，不写文字内容。
- 手写标语牌类：核心文字优先直接使用用户原文；若是完整短句则逐字一致，不得改写。
- 通用禁令：画面中除指定文字外不出现任何其他可读文字、乱码、水印。

## 8. 弱表达 → 硬表达替换表

模型对弱词执行不稳定，写提示词时替换：

| 弱表达 | 硬表达 |
|---|---|
| full body | head-to-toe full body, including feet, no cropping |
| 美丽的 | 具体特征（杏眼/高鼻梁/瓜子脸…） |
| 高级感 | 具体材质+配色+构图特征 |
| 简约 | minimal composition, single subject, negative space ≥40% |
| 特写 | extreme close-up on [部位], filling ≥80% of frame |

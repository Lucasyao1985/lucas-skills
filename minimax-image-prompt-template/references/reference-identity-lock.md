# 参考图协议、身份锁与编辑替换子句

## 1. 参考图四要素协议（Name + Role + Take + Ignore）

引用参考图时逐项声明四要素，禁止重复描述参考图已编码的内容：

```
Name:  the model from Reference 2（命名引用，不重写外观）
Role:  身份来源 / 风格来源 / 构图来源 / 配色来源 / 仅氛围
Take:  从参考图提取什么（"retain her hairstyle, face shape and outfit silhouette"）
Ignore: 忽略什么（"ignore its background, lighting and color grading"）
```

核心纪律：**参考图已经确定的信息用指代**（"the character in Picture 1"），不凭空重写特征；提示词中禁止出现"参考图/输入图片/变量/image1"等制作流程术语——直接描述最终画面，用"照片中的人物/图中的角色"这类表述。

## 2. 身份锁卡（Identity Lock）

- 从参考图逐项读取**最具辨识度的 8-12 项**特征，写入提示词：脸型、五官比例、眼型、发型、发色、肤色、体型、服装结构、配饰、标志物。
- **无法判断的不写**；禁止补充参考图中没有的属性；禁止把某一次生成结果的特征写死。
- 特征必须具体到位置/左右/数量/材质/比例，禁止"美丽的/英俊的"笼统词。
- 成套图/后续批次：身份锁卡**逐字复用** + 附同一张参考图；锚定上一批**实际成图**而非计划文案。

## 3. 视觉类型保持规则（不互转）

输入照片是写实真人→全图保持写实摄影质感；是动漫→保持该动漫画风；是 3D/像素/卡通/插画→保持对应类型。除非用户明确要求，**禁止**写实↔动漫↔3D 互转。每个涉及人物的区域（头像/正文配图/标语牌人物）分别声明一次类型保持。

## 4. 编辑替换三子句（R1/R2/R3）

### R1 系列一致性锁（成套图重生时）

```
本图属于已批准系列。以下属性必须与系列其他图（附为参考）完全一致：
产品外观(色/包装/文字/材质)、模特身份(脸/发/肤色/比例)、穿搭(每件单品)、
场景族(表面/墙面/时辰/调色/光向)、复现道具状态。
本次重生仅允许改动：{显式清单，仅此而已}。
```

### R2 局部编辑范围锁（改一张图的局部）

```
这是局部编辑不是重生。以附图底图为画布。唯一改动区域是{显式区域}。
其余所有像素必须与底图完全一致。不得调整姿势、光照、背景、调色或任何其他元素。
新区域的纹理/颜色/光照须匹配底图周围像素，使编辑不可见。
```

头号 bug 防范：局部编辑必须走 image-edit 模式（底图当画布），绝不能跑成 fresh seed 文生图（否则模特/背景/灯光全变）。

### R3 材质修复锁

```
附原产品参考图为 texture source-of-truth。修复区域的纹理渲染必须与参考图完全一致，
不得发明纹理，镜像参考的微表面/织纹密度/光洁度。
```

组合表：局部修 = R1+R2(+R3)；全图重做保系列 = R1(+R3)；换方向重做 = 都不加。

## 5. 保主体重打光（relight 范式）

槽位：最多 3 盏灯（类型/入射角/色温/强度/软硬）+ 背景处理（保留/纯黑/纯白）+ 氛围特效 + 风格预设。
失败恢复顺序：画面变平 → 先拉开主光/辅光/轮廓光；阴影冲突 → 先归一盏主光再逐盏加。

## 6. Remix 三轴拆解（保留氛围换主体）

把参考图拆 10 维（构图/画风/色彩/光影/氛围/质感/主体处理/叙事/后期/媒介），坍缩为三轴：

- **形 Form**：构图与结构关系
- **韵 Aesthetic**：画风、色彩、质感、媒介
- **意 Mood**：光影、氛围、叙事情绪

生成一句话 soul summary → 与用户确认"保留哪几轴 / 替换哪几轴" → 只改受影响轴（"颜色冷一点"→只动色彩轴语言）。负向必含：禁复制原主体、禁水印、禁网格拼贴、禁风格漂移。

## 7. 字形/字效迁移（brand-font-effect-editor 范式）

- 字体名模型不可靠，**必须转译为视觉特征**：字重（笔画粗细）、字距、端点形状（圆/方/尖）、字腔大小、有无衬线、特殊效果（描边/渐变/高光/外发光）。
- 编辑指令自包含：目标位置 + 源特征完整视觉描述 + **必须不变的元素清单**。
- "仅迁移字形"时强调：保留目标图全部原有效果（颜色/材质/光效不动，只换字形骨架）。

## 8. 顺序生成链（多资产系统类）

IP 资产包/纹样系统类项目**严禁一跳到底**，固定顺序：

```
母版(正面写实) → 白底提取母版 → 无缝连续纹样 → 配色方案(带HEX标注)
→ 样机(flat-lay) → 壁纸(多画幅) → 动效(交视频skill)
```

每步产物经确认后才进下一步；多张参考图各自独立成套，禁止混合母版；换参考 → 从受影响的母版重建，禁止新旧混拼。

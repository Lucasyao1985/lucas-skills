# 音画设计：声音两段分离、SFX 分层、卡点

## 1. 两个声轨字段（永不分混）

| 字段 | 内容 | 示例 |
|---|---|---|
| `overall_soundscape` | 叙事内声（diegetic）：环境声、动作音效、UI音、非词语气声、对白 | 脚步声、布料摩擦、门吱呀 |
| `non_diegetic_music` | 观众向配乐（BGM） | `N/A` 或一段配乐描述 |

- 不要配乐时：`non_diegetic_music: N/A`，且不额外添加背景音乐。
- 对白/旁白写进 overall_soundscape（或按 multi-shot 的 Audio Track 列），逐字写台词、指明谁说、句长匹配镜头时长。

## 2. SFX 分层五元组

每个动作节拍对应一种材质音，按五元组写：

```
触发动作 + 声音材质 + 距离层(近/中/远) + 时长/衰减 + 与画面的同步点
```

示例：`delicate contact sound when the teapot lid is set down (close perspective, decays within 0.5s, synced to the exact touch frame)`。

SFX 纪律五条：
1. 元素未入场不放音
2. 不叠音（同一时刻一个主动音）
3. 入场起音、落定衰减
4. 材质决定音色（依参考图材质逐材质写，不得笼统合并）
5. 每个动作节拍恰一种主材质音

## 3. 卡点映射表（beat-sync）

| 音乐事件 | 画面响应 |
|---|---|
| hi-hat 滚奏 | 微震 / 跳帧 / 小字距重排 |
| 军鼓 | 硬切 / 文字 punch-in / 肩头重音 |
| 808 低音 | 低频画面压缩 / 闪白 / 文字拉伸 |
| 人声关键词 | 口型 / 下颌 / 点头 / 手势 |
| drop | 全屏爆发 / 慢镜转快镜 |
| 停顿 | 冻结帧 / 声音骤停留白 |

禁随机文字运动：文字动效必须有因果（被动作牵引/落在拍点）。

## 4. 音频事件 → 画面写法对照

```
鼓点   = 爆发定拍（切点/落点/重音帧）
弦乐   = 曲线流动（运镜轨迹/衣摆飘动）
歌词   = 字卡与口型（逐字对应，窗口锁死）
停顿   = 冻结（人、字、粒子全静止，仅镜头可动）
drop   = 全屏爆发（色彩/粒子/文字同时释放）
```

## 5. 音乐四段律（15s 配乐描述模板）

```
0-2s   动机（单一音色进入，建立基调）
2-8s   推进（层次叠加，节奏加密）
8-12s  对比/蓄势（抽层或降速，制造期待）
12-15s 高潮 + 明确终止音
```

只锁三样：风格、情绪、2-4 个音色锚；不锁 BPM 与和弦走向。
子弹时间/定格：音乐骤降（duck）→ 只留空间底噪 → 重启瞬间强拍回归。

## 6. 旁白 / 对白规则

- 说话窗不重叠 + 0.20s 守卫间隔（含跨镜）。
- narration 秒内所有在屏角色闭嘴（mouth:closed）+ 写表情路径（expression-path）。
- 对白只用视频原声，禁 TTS 替换对白；旁白可后期独立音轨（VO 替换层：视频确认后按成片真实时间线生成）。
- 跨镜一句话写"承接上镜"；画外音转画内要写过渡。
- 画面永不出现字幕/标题/文字 UI（对白只走声音），除非用户明确要求字幕——要求时走字幕替换模板（replacement-editing.md §4）。

## 7. 拟音风格库（按情绪锁一套，避免音效词汇漂移）

```
克制奢华系：织物摩擦/瓷器轻碰/珠链滑动/低沉留白
梦境怪核系：荧光灯嗡鸣/潮湿地毯脚步/远处空调低鸣/电流杂音
高能时尚系：锐利打击乐/布料甩动/镜头风声/节拍脉冲
手绘童趣系：马克笔沙沙/纸张摩擦/轻盈弹跳/风铃点缀
```

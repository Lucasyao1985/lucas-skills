# 多镜头连续性

## 1. 时长 → 镜数换算

| 成片时长 | 镜数（叙事默认） | 说明 |
|---|---|---|
| ≤15s | 6-10 镜 | 单条 H3 直接出 |
| 15s=8镜 / 30s=15镜 / 45s=22镜 / 60s=29镜 | 分段生成后拼接 | 每段 ≤15s |
| 单镜上限 | 15s | 超过必拆镜 |

普通镜头 0.8-2.2s，短插入 0.25-0.65s，片名/定格段 1.4-2.4s。密度路由：实拍 AE 类 8-11 镜、架空特效 7-9、编辑拼贴 8-12；电影叙事不设数量、按完整动作切。禁止前半密切后半只剩长段。

## 2. 七列分镜表（逐镜规划的最小完整格式）

| 列 | 内容 |
|---|---|
| Shot ID & Duration | 镜号 + 时长窗（0-3s / 3-5s…） |
| Continuity Handoff | 承接：上一镜尾帧的什么状态被继承 |
| Reference Anchors | 本镜绑定的参考图/角色卡 |
| Hook Type | 钩子类型（受控词表：悬念/反转/揭示/视觉奇观/情绪） |
| Per-Second Directives | 逐秒六要素：动作 / 相机 / 空间 / 声音 / 口型 / 衔接 |
| Audio & Dialogue Track | 本镜音频事件 |
| Audio Mode | silent / dialogue-led / narration-led |

### C1-C7 连续性字段（每镜带）

```
C1 空间锚（在哪）  C2 出场状态（从什么状态进入）  C3 光照继承
C4 时间线          C5 色调                        C6 主次强度
C7 强弱帧选择（哪帧是本镜记忆点）
```

## 3. 五大连续性锁（音乐视频/拼接类）

1. **人声口型连续**：切点落在换气/军鼓/drop，禁在元音中硬切。
2. **节拍匹配**：对齐 1/4 或 1/8 节拍网格，点头/手势/眨眼落在拍点。
3. **美学统一**：每镜带同一美学头 prompt；后期统一颗粒+LUT 掩盖批次色差。
4. **运动衔接**：长镜尾帧接首帧续写动作；硬切用同向横摇/手部遮挡匹配切。
5. **字体动量传递**：前镜文字在 bass 点炸出，后镜文字在重音砸入。

## 4. 跨提示词交接（handoff 段）

分段生成时，下一条提示词开头写上一段结尾的可见状态：

```
Continuing from the previous segment: {角色} stands at {位置}, {动作末态},
{光照状态}, camera {机位与焦距}. The next action begins from this exact state.
```

"保持一致"不算事实——必须写可见状态（位置/姿势/光照/机位）。

## 5. 相邻镜桥接规则

每个转场必须显式写：**前段什么元素 → 变成 → 后段什么元素**，时长多少，镜头怎么动。禁"自然过渡/流畅切换"空话。

转场四元组：`可见来源 → 切点 → 继承项 → 新落点`。转场家族至少用 2-3 类：动作匹配切 / 形状匹配切 / 前景遮挡切 / 声音桥。

## 6. 双镜头节奏律（场景叙事型短片）

每个叙事场景固定两镜：
- **Shot A 定场**（约 3s）：前中后景 + 唯一克制运镜，交代空间。
- **Shot B 跟近**（约 3s）：一个精确动作 + 微表情/细节。

## 7. 时长硬门公式（旁白/对白驱动）

```
voice_required_seconds = 有效字数 ÷ 语速(字/秒) + 标点停顿
target = voice_required_seconds + 1-2s 视觉缓冲
提交时长 = 最短合法时长
```

- 旁白窗先于镜头时长锁定；`narration_end + 0.20s <= dialogue_start`（含跨镜）。
- 超窗处理：拆镜/移窗/延镜，禁压速。
- narration 秒内所有在屏角色 mouth:closed + 必写 expression-path；对白单说话人（反应用 reaction-cut 拆镜）。

## 8. 镜头内部模板（成片级，每镜 11 字段自然语言展开）

```
【镜头 N｜start–end｜新增信息】
景别与相机（焦段/稳定方式，从起点沿唯一路径到终点，揭示什么，稳定多久）
→ 人物/主体与环境 → 画面效果（主效果：来源→路径→接触→结果→结束 + 2-3支撑反馈）
→ 文字与版式（无文字也要明写"本镜无文字"）→ 转场（可见来源→切点→继承项→新落点）→ 声音
```

硬规则：每镜**一个确定运镜**（出现"横移或慢推/可以使用/例如"= 未决，禁止派发）；全片覆盖 3 种摄影功能（建立揭示/行动跟随/证据靠近/尺度释放）。

## 9. 叙事弧模板

```
hook(0-2s) → 主体建立 → 发展/递进 → 阻碍 → 升级 → 高潮 → 收束 lock-up(定格)
```

预告片因果链：`[主体状态]→[触发]→[阻碍]→[行动]→[升级]→[未解决]→[片名]`。

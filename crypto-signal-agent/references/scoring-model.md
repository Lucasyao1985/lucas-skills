# 因子评分模型（v2.4）

> 所有子分归一化到 **[-100, +100]**，正=偏多，负=偏空。
> 与 `scripts/signal_agent.py` 一一对应；本文件是公式细节的权威说明。
> BTC/ETH 为 14 子因子（含 ETF 资金流）；其他币种 13 子因子。

## 2. 关键公式

### EMA 对齐
```
bull_count = Σ weight_i × [EMA9_i > EMA21_i]    (i ∈ {1h:3, 15m:2, 5m:1})
ema_score  = (可用权重内 bull_count / max_w) × 200 − 100
数据不足的周期不计入分子与分母（中性处理），而非默认看空。
```

### 价格结构（15m 近 10 根）
```
HH∧HL → +80   LL∧LH → −80   其他 → 0
```

### RSI
- 完整序列一次性计算 Wilder RSI，再按索引取值（禁止滑动窗口重复计算）。
- 底背离（价新低+RSI不新低）→ +60；顶背离 → −60；
- RSI>70 → −30；RSI<30 → +30。

### 资金费率分层（原始小数！）
| lastFundingRate | 分值 |
|---|---|
| > +0.0005 | −80 |
| > +0.0002 | −40 |
| < −0.0003 | +80 |
| < −0.0001 | +40 |
| 其余 | `rate × (−100000)` 线性 |

### OI 评分（真实历史）
```
oi_change_pct = (oi_now − oi_1h_ago) / oi_1h_ago × 100     ← openInterestHist
px_dir        = +1 若最近两根1h收盘上涨，否则 −1
oi_score      = clip(oi_change_pct × 10 × px_dir)
```

### 订单簿
```
wall_score = clip((Σbid额 − Σask额) / 总额 × 200)           # 全100档
conc_score = (最大买单档占比 − 最大卖单档占比) × 200          # 前10档内
```

### 现货 ETF 净流入（v2.4，仅 BTC/ETH）
```
sum3      = 近3个已报告交易日净流入合计（$M，Farside，抓取见 etf-flows.md）
etf_score = clip(sum3 / 5, −80, +80)     # 顺势因子！±400 $M/3日 → 满分
注意：与 F&G/资金费率的逆向语义相反——机构净流入=增量买盘=利多。
日线 T+1 慢变量，连续 3 日同向才有含义。
```

### 合成
```
composite = 0.30×趋势 + 0.20×量能 + 0.25×衍生品 + 0.15×订单流 + 0.10×情绪
方向死区: composite ≥ +35 → 做多; ≤ −35 → 做空; 否则观望
```

### 辅助输出
```
一致性 = 5 组分数中与 composite 同号的数量
胜率   = min(40 + |composite|/2 + 一致性×4, 85)
信号强度 = int(|composite|)
```

## 3. 刻意降权的因子（防假信号）

- RSI 单独仅 4.5% 全局权重——趋势结构优先。
- 绝对价格位不直接进模型——只通过结构/H/L 关系体现。
- 社交媒体情绪不采集——对 1 小时展望噪声过大。

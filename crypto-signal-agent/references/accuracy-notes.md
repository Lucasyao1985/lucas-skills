# 准确率设计与工程决策（v2.4）

## 1. 减少假信号

| 问题 | 对策 |
|---|---|
| 单周期假突破 | EMA 对齐需多周期共振，且数据不足的周期按中性处理而非默认看空 |
| 强趋势中 RSI 超买钝化 | RSI 全局权重仅 4.5%，趋势结构优先 |
| 震荡市资金费率噪声 | 仅在原始小数 >±0.0002 时启用逆向分层 |
| 低量假突破 | 量比仅统计**已收盘**K线（未收盘蜡烛量必然偏低，会虚假压分量能分） |
| 弱信号硬给方向 | ±35 死区 + `AMBIGUOUS_SCORE` 双保险，宁观望不出弱方向 |
| 假 OI 数据 | 旧版用价格变动冒充 OI 变化；v2.2 起使用 openInterestHist 真实历史 |

## 2. 防缓存污染

- 每次执行独立抓取全部端点；无落盘缓存、无进程间状态。
- K 线新鲜度以服务器 `closeTime` 为准（非本地时钟）。

## 3. API 配额紧张时的抓取优先级

1. **必抓**（缺失=无信号）: ticker、15m/1h K线、funding
2. **应抓**（缺失=降置信）: depth、aggTrades、OI 历史、4h/5m
3. **可选**: 备源交叉验证

降级模式下（仅第 1 层）：confidence 上限 0.65，观望死区放宽到 ±45。

## 4. 权重影响排序（速查）

```
改变方向级:  EMA对齐 13.5% | OI×价向 10% | 价格结构 12%
强化方向级:  资金费率 8%+5% | RSI 4.5% | 量比 8% | Taker失衡 7% | 墙失衡 8.85% | 多空比 7%
微调分级:    量趋势 5% | 大单集中度 6.15% | F&G 5%
```

## 5. 已知局限（诚实声明）

- 目标持有期 **1 小时**；用于 <5min 或 >1天 场景需重新校准权重。
- BTC 流动性深于山寨币，同分值下大币信号先验可信度更高（v2.4 已按币校准风控阈值）。
- 模型不含链上数据、订单流逐笔回放。
- ~~宏观事件盲区~~ → **v2.3 已补**：事件静默窗 + BTC 联动门控（见 macro-layer.md）。
  但政策**预期变化**（点阵图转向、官员讲话措辞）仍需运行 skill 的 LLM 结合新闻判断。
- ETF 资金流为日线 T+1 慢变量，且仅覆盖 BTC/ETH；山寨币机构背景由 BTC 联动门控
  间接传导。Farside 被 Cloudflare 保护，脚本层不可达（v2.4 起由模型层 WebFetch
  抓取后经 CLI 传入，见 etf-flows.md）。
- 本工具只产生研究性方向信号，**不下单、不构成投资建议**。
